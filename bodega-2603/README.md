# Bodega 2603

La bodega guarda los lotes que ya terminaron su destilación. Cada libro tiene su portada y, pasando el cursor por encima, un extracto de lo que quedó. Es una vitrina: se mira, se elige y se abre.

Lo guardado aquí es una página en HTML, hecha para leerse en el navegador.
