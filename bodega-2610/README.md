# Bodega 2610

La segunda bodega de la Destilería, abierta en octubre de 2026. El nombre sigue la forma año y mes: 26 y 10.

Aquí se guardan ocho lecturas de *Macbeth*. Cada una la hizo un motor de embeddings distinto, con la misma receta, y cada una eligió sus propios pasajes. Las páginas son HTML, hechas para leerse en el navegador.
