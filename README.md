# Destilería

Una destilería es un lugar donde se destila: se separa una sustancia mediante evaporación y condensación. *Destilar* viene del latín *destillare*: caer gota a gota.

Aquí se ensaya algo parecido con los libros: quitar lo que sobra hasta encontrar una forma breve que conserve su fuerza y se pueda contar a otro. Es una hipótesis de trabajo, no una promesa cumplida.

La destilería conduce a tres salas:

- [Protocolos](protocolos/README.md): los instrumentos y las convenciones para leer y destilar.
- [Bodega 103](bodega-103/README.md): los primeros lotes de la casa, elaborados y guardados para que se vea de dónde viene la casa.
- [Bodega 110](bodega-110/README.md): lo que la casa está destilando ahora, listo para leer.
